# Meraj UI Kit

Create a modern, premium, responsive Islamic website UI only for a mosque named "Masjid-e-Meraj" (مسجد معراج).

IMPORTANT:

- Design only the frontend UI.

- Do NOT create authentication, backend, database, APIs, or any functionality.

- Use placeholder content where needed.

- Focus on layout, typography, spacing, colors, and user experience.

Design Style:

- Premium, elegant, clean, and minimal.

- Inspired by Islamic architecture.

- White, emerald green, gold accents, and subtle beige backgrounds.

- Rounded cards, soft shadows, and glassmorphism where appropriate.

- Beautiful Arabic-inspired typography.

- Smooth scroll animations.

- Mobile-first responsive design.

Navigation:

- Logo (Masjid-e-Meraj)

- Home

- Prayer Times

- Quran

- Events

- Gallery

- Contact

Hero Section:

- Full-screen hero with a beautiful mosque silhouette in the background.

- Elegant Arabic calligraphy decoration.

- Title: "Welcome to Masjid-e-Meraj"

- Subtitle: "A place of worship, peace, learning, and community."

- Primary Button: "View Prayer Times"

Prayer Times Preview:

Display six elegant cards:

- Fajr

- Dhuhr

- Asr

- Maghrib

- Isha

- Jumu'ah

Use placeholder prayer times.

About Section:

- Mosque image placeholder.

- Brief description of the mosque.

- Three feature cards:

  - Daily Prayers

  - Quran Classes

  - Community Services

Upcoming Events:

Display three premium event cards with placeholder information.

Gallery Preview:

Display six responsive image placeholders in a clean masonry or grid layout.

Testimonials:

Display three elegant testimonial cards from community members.

Footer:

- Masjid-e-Meraj

- Address placeholder

- Contact information placeholder

- Social media icons

- Copyright

Extra Requirements:

- Smooth animations.

- Modern icons.

- Premium spacing.

- Beautiful gradients.

- Consistent reusable UI components.

- Accessible color contrast.

- Fully responsive for desktop, tablet, and mobile.

- Generate only the visual UI with no backend or functionality.
